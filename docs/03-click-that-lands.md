# 03｜点得中：时机、焦点、遮挡与点击方式分级

> 「让 GUI 自动化更精准」系列第 3 篇。定位分毫不差，点击却石沉大海——问题不在"点哪"，在"什么时候点、以什么方式点"。

[返回目录](../README.md#技术专栏让-gui-自动化更精准)

## 点击失败的四种真实原因

`Click()` 返回成功，界面没反应。逐一排查这四个方向，命中率超过九成：

1. **时机不对**：控件还在加载中、处于禁用态、或页面正在重排
2. **焦点不对**：目标窗口不在前台，或点击被别的窗口接收
3. **遮挡**：目标点上有透明层、提示气泡、悬浮窗
4. **方式不对**：用坐标模拟点击，而控件其实支持更可靠的调用方式

## 时机：等状态，不要 sleep

固定 `sleep(2)` 是自动化脚本最大的不稳定来源：网络快时浪费时间，网络慢时点了个寂寞。正确姿势是**等待条件成立**：

```python
def click_when_ready(el, timeout=10):
    deadline = now() + timeout
    while now() < deadline:
        if el.exists and el.is_enabled and not page_is_loading():
            return el.invoke_or_click()
        sleep(0.3)
    raise TimeoutError("control never became ready")
```

两个加分项：

- **窗口稳定检测**：窗口刚弹出/切换时布局还在动。连续 2~3 个采样点窗口位置与尺寸不变，再开始操作，可避免"点在动画中间"
- **页面就绪信号**：优先用应用自己的信号（标题栏去掉"加载中"、进度条消失、关键元素出现），比拍脑袋的延时可靠得多

## 焦点：前台化要"验证成功"，不要"假设成功"

`SetForegroundWindow` 在 Windows 上有诸多限制（用户正在交互、前台锁超时），调用后可能静默失败。点击前必须验证：

```python
bring_to_front(target_hwnd)
if get_foreground_window() != target_hwnd:
    retry_bring_to_front()          # 重试 / 用最小化还原 / 附加线程输入等手段
```

前台化本身也要挑时机——检查目标是不是渲染窗口（见[第 1 篇](01-find-the-right-window.md)），把影子窗口设为前台是常见翻车点。

## 遮挡：点击前先问"谁会收到这次点击"

点击前用 `WindowFromPoint` 反查目标坐标处的实际接收窗口：

- 接收窗口 == 目标窗口 → 放心点
- 接收窗口是提示气泡 / 弹窗 / 悬浮球 → 先关掉遮挡物再点，或改用元素级调用绕过坐标

这一步检查还能顺带捕获**意外弹窗**（升级提示、广告弹层）——检测到预期外的接收窗口，交给上层决策处理，而不是硬点下去。

## 点击方式分级：从最可靠到最保底

同一个"点击"有四种实现，可靠性依次递减：

| 级别 | 方式 | 说明 |
|:----:|------|------|
| 1 | **Pattern 调用**（如 InvokePattern） | 消息直达控件，不经过坐标与焦点，永不偏移 |
| 2 | **元素中心点 + 校验点击** | 坐标点击，但点前校验 `WindowFromPoint` 命中 |
| 3 | **坐标模拟点击** | 纯物理坐标，任何场景可行，需搭配强验证 |
| 4 | **键盘导航** | Tab/方向键 + 回车，控件树完整时的低成本替代 |

策略：**能用 1 绝不用 2**。Pattern 调用几乎免疫前面所有问题（时机问题仍需等待解决）。只有控件树不可用（自绘 UI）才落到 2/3。

## 失败回流：单步也要小验证

不要等整个任务结束才验证。每步点击后立即做一个**廉价局部验证**：

- 点击按钮 → 期望某个新元素出现 / 按钮态变化 / 页面标题变化
- 局部验证失败 → 换下一级点击方式重试（1 → 2 → 3），仍失败则带着差异信息进入全局重规划

局部验证的另一个作用是**把错误发现得足够早**：第 1 步点错了位置，第 2 步之前就能发现，而不是跑完 10 步才发现全盘皆错。

## 小结

- 等条件，不 sleep；等窗口稳定，不在动画中操作
- 前台化必须验证结果；对渲染窗口操作，不对影子窗口
- `WindowFromPoint` 预检，遮挡与意外弹窗提前暴露
- 点击方式分级：Pattern > 校验点击 > 坐标 > 键盘
- 每步小验证，失败早回流
