# PalatMind — Windows 桌面 AI 智能体

PalatMind 像人一样使用电脑：**看得见屏幕、看得懂页面、点得准鼠标、一步一步把事办成**。

你说「打开酷狗播放周杰伦的《晴天》」「把这份 Excel 汇总成周报」「每天早上总结未读邮件」，它就直接在你的电脑上做出来——不需要写脚本，不需要为目标应用做适配。

- 下载：https://palatmind.com/download/ （Windows 10/11 x64）
- 文档中心：https://palatmind.com/docs/

## 它是怎么操作电脑的？

一次桌面任务背后，是一条完整的「感知 → 理解 → 操作 → 沉淀」链路。这个系列按环节逐个拆解，分享我们把它做到稳定精准的通用技术：

| 环节 | 文章 | 内容 |
|:---:|------|------|
| ① 看得见 | [01 看得见屏幕](docs/01-see-the-screen.md) | OCR 精准识别页面文字 + 图标元素小模型检测 |
| ② 看得懂 | [02 看得懂页面](docs/02-understand-the-page.md) | 理解页面结构，知道该点的元素在什么位置 |
| ③ 点得准 | [03 点得准](docs/03-precise-click.md) | 结合鼠标的使用：单击、双击、拖拽、滚轮的精准操作 |
| ④ 步步执行 | [04 一步一步执行](docs/04-step-by-step.md) | 把一句话目标拆成步骤序列，逐步执行、逐步确认 |
| ⑤ 越用越快 | [05 成功案例变脚本](docs/05-success-to-script.md) | 执行成功的案例自动沉淀为可复放的自动化脚本 |
