## 这是什么？

PalatMind 是一款面向 Windows 的桌面 AI 智能体。你用自然语言下达任务，它直接在你的电脑上完成：

- 「打开酷狗，播放周杰伦的《晴天》」——它真的去点开应用、搜索、播放，并确认歌名出现在播放栏
- 「帮我把这份 Excel 按月汇总成周报」——它打开文件、读取数据、生成文档
- 「每天早上 9 点帮我总结未读邮件」——定时任务自动执行

不需要写脚本，不需要为目标应用做适配，像指挥一个坐在你旁边的助手。

## 核心能力

- **自然语言操作电脑**：直接操作真实应用与窗口——浏览器、办公软件、播放器、聊天工具
- **文档与演示创作**：一句话生成 Word、Excel 报表、PPT
- **信息获取与研究**：联网搜索、多来源交叉验证、自动整理成文
- **语音交互**：语音下指令，语音播结果
- **定时任务**：到点自动执行，结果主动推送
- **跨会话记忆**：记住你的偏好与上下文，越用越顺手
- **安全分级审批**：敏感操作执行前确认，危险操作强制确认，全程可控

## 快速开始

1. 前往 [官网下载页](https://palatmind.com/download/) 获取安装包（Windows 10/11 x64）
2. 按安装向导完成安装，注册登录
3. 用一句自然语言下达你的第一个任务

## 技术专栏：让 GUI 自动化更精准

|------|-------------|
| [01 找对窗口](docs/01-find-the-right-window.md) | 为什么你点的"那个窗口"根本不是渲染窗口——影子窗口、DPI、多显示器三大陷阱 |
| [02 找对元素](docs/02-find-the-right-element.md) | 控件树里啥都没有怎么办——UIA 与视觉识别的双通道定位与融合 |
